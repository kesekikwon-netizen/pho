2. 면(차수 이름): 시안 검출면/반절/완굴/기타 → 기존 검출면/중간/완토/바닥 유지(장부·목록.csv 값)
3. 새 대상 차수: 시안 1–4차 고르기 → 새 대상은 항상 1차, 2차부터는 폴더 안 「차수」에서(앞 차수 잠금·파일 보존)
4. 파일 이름: 시안 「표적.xml/표적.txt」·「광령리1_20261012.zip」 → 실제 이름 그대로(005호_주거지_1차_EPSG5187.xml/.txt · 유적_전달_날짜.zip · 유적_목록.csv). iTwin XML 바이트 형식 변경 없음
5. 폴더: 시안 「005호_주거지_1차」 폴더 → 실제는 대상 폴더 005호_주거지 안에 차수 파일. 화면의 폴더 표시는 사진 폴더 이름(…_1차)
6. 사진 단계: 시안 ID 카드·사진 찍기 따로 → 실제는 ID 카드 화면의 「사진 다 찍었어요」 하나로 사진 단계 끝(앱이 카메라를 직접 다루지 않음)
7. 표적 재기 단추: FIX 가 아니면 막힘(「FIX 기다리는 중」), 수신기 없으면 「수신기 연결」, 앞 차수는 보기만 — 시안에는 없는 상태
8. 재는 중: 시안 「흩어짐 0.6 cm」 → 수신기 GST 정밀도(σ)를 표시(측정기 코드 변경 없음). FIX 가 끊기면 저장 없이 멈춤
9. 상태 알약: 시안 「● FIX」 → FIX 일 때 정밀도 cm 를 함께, 그 밖엔 FLOAT/FIX 대기/연결 안 됨/측량 불가
10. 폴더 목록 위 거르기(표적·사진·보낼·끝) 추가 — 100개 넘는 대상 대비(시안에 없음)
