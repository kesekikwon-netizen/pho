# 사진 기준점 변경 기록

## 0.1.0 (첫 버전)
- iTwin Capture 표적 측점만 하는 별도 앱. 측량앱과 따로 설치되고 아이콘도 다릅니다(진한 먹색 바탕 + 표적).
- 유적 → 대상(유구·토층·기타) → 차수 → Target #번호. 대상마다 바뀌지 않는 ID(예: GN-001)가 폴더·XML·목록 이름 앞에 붙습니다.
- 표적을 잴 때마다 XML·TXT가 `Documents/iTwinGCP/<유적>/<ID>_<대상명>/`에 바로 저장됩니다(강릉 1호 형식).
- 관리판 맨 위 숫자 칸(측점 필요·사진 필요·전달 필요·끝)을 누르면 그 대상만 보입니다.
- ID 카드(QR)를 사진 첫 장으로 찍고, 다 찍으면 「사진 다 찍었어요」.
- 표적 3개 미만, 다시 잰 값 2 cm 넘게 차이, 가까운 대상과 번호 겹침을 알려 줍니다.
- 「PC로 넘기기」 한 번으로 목록.csv와 대상별 XML을 zip으로 보냅니다.
- 수신기(R10·SP60)·VRS·위성/지적 지도는 측량앱 0.1.37 코드를 그대로 씁니다. FIX일 때만 잽니다.
