**화면이 측량 앱과 같아졌어요**
- 유적을 열면 바로 넓은 위성지도 + 지적도(측량 앱과 같은 지도 코드). 위에는 측량 앱과 같은 상태 알약(측량 가능 ±cm), 아래에는 「지금 재는 것」 + 폴, Target 단추 줄, 차수 · ID 카드 · 큰 「측량하기」
- 「측량하기」는 안 잰 첫 표적을 재요. 다 쟀으면 다음 빈 번호를 더해서 재요
- 지도에는 대상마다 표적 모양과 둘레 점선 + 이름(지금 대상은 #번호까지)

- 차수: 검출면·중간·완토·바닥 타일
